AevonMC Font Toolbar Update

Upload admin.html, admin.js, admin.css, app.js, styles.css to the repository root.
These are based on the prior Rich Editor update. No posts or credentials are included.

In the admin editor select text and choose a font family or font size, then click Apply font or Apply size.
Font changes are saved as {{font:Arial|text}} and {{size:24|text}} in posts.json.
Google Fonts load when internet access is available. Other fonts require installation on the visitor device and fall back to browser fonts.
Nested formatting tokens are not fully supported: apply each font/size to a simple selected text segment.
